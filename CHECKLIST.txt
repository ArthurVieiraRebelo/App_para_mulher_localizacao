🚀 COMO COMEÇAR
────────────────────────────────────────────────────────────────────────────

OPÇÃO 1 - Rápido (Windows):
   1. Duplo clique em iniciar.bat
   2. Abra http://localhost:5000
   3. Pronto! ✅

OPÇÃO 2 - Rápido (Linux/Mac):
   1. chmod +x iniciar.sh
   2. ./iniciar.sh
   3. Abra http://localhost:5000
   4. Pronto! ✅

OPÇÃO 3 - Manual:
   1. python -m venv venv
   2. venv\Scripts\activate (ou source venv/bin/activate)
   3. pip install -r requirements.txt
   4. python setup.py
   5. python app.py
   6. Abra http://localhost:5000
